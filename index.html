Details & exports

Quality and representation

Selected detail count is a budget before quantization. Quantization may turn additional values into zero. The reported file size is actual compact JSON bytes, not an estimated image compression ratio. Sparse JSON can be larger than the original image or an optimized codec.

PSNR and MSE compare rounded, clipped byte reconstruction with the grayscale source. Raw inverse-transform error is also reported separately and obeys the orthonormal coefficient-energy identity. Coefficient imports contain no source image, so reference quality is unavailable.

Processing boundaries

Images are flattened onto white, fitted within a 128 × 128 white square without cropping, and converted to encoded-channel grayscale using weights 0.2126, 0.7152, and 0.0722. This is not a linear-light or color-preserving pipeline. PNG/JPEG/WebP files are limited to 8 MiB and 16 million decoded pixels.

Coefficient files support square sizes 32, 64, 128, and 256, up to full decomposition depth, and integer quantization steps 1–128. They are inspectable sparse transform data, not JPEG 2000, an entropy-coded format, an encrypted container, or authenticated evidence. All processing stays in this browser.
